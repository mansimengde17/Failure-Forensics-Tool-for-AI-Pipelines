Observability for multi step AI

Failure Forensics Tool for AI Pipelines

When a multi step pipeline produces garbage, this tool answers 'where did it go wrong?' in seconds: full span tracing, backward root cause analysis, and a growing eval dataset built from confirmed failures.

This simulation runs the system's real decision logic directly in your browser. Click a red trace to watch the analyzer walk the spans backward and pin the root cause with evidence.

Architecture

How a request moves through the system.

1
Instrumented pipeline

A four step document pipeline (intake, extraction, classification, summarization); each step is a typed function wrapped by a one line tracing decorator.

2
Span capture

Every span records input, output, prompt, raw response, tokens, latency, and the model's self reported confidence.

3
Backward analyzer

On a flagged trace, each step's output is scored as a transformation of its input, walking backward; the earliest quality drop is the root cause.

4
Failure taxonomy

extraction_hallucination, misclassification, propagation_error, prompt_failure, context_loss; every diagnosis carries an evidence chain with exact input/output quotes.

5
Feedback to eval loop

Confirmed diagnoses become regression cases; rerunning them tracks which known failures stay fixed.

How to use

Runs fully offline with a deterministic provider; add API keys to switch to live models.

# offline: trace 12 documents, diagnose the failures
pip install -r requirements.txt
python demo.py
# -> root cause: step 2 (extraction), extraction_hallucination

# serve the trace explorer API
uvicorn src.forensics.api:app --reload
curl -X POST localhost:8000/v1/traces/tr-xxxx/flag
